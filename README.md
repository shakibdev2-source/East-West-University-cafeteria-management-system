## 📌 Overview
The **East West University Cafeteria Management System** is a full-stack web application designed to automate campus cafeteria operations. It simplifies food ordering for students, automates billing & payments, and provides real-time management and analytics tools for cafeteria administrators and staff.

## 🛠️ Tech Stack & Database Architecture

* **Frontend:** HTML5, CSS3, Tailwind CSS, JavaScript (Custom Responsive UI, Glassmorphism Design, DOM Manipulation)
* **Backend:** PHP (Role-Based Authentication, Business Logic, Session State Management)
* **Database:** MySQL (Relational Schema Optimization, SQL Queries & Refactoring)
* **Security:** CSRF Validation, Dynamic Session CAPTCHA System, HTML Output Sanitization

---

## ✨ Key System Features

* 🔐 **Multi-Role Access Control:** Custom portals for Admin, Students, Faculty, and Staff.
* 🍔 **Dynamic Menu Management:** Full CRUD operations for menu items and food categories.
* 🛒 **Live Cart & Direct Checkout:** Dynamic calculation with receipt generation.
* 💳 **Payment Integration:** Integrated bKash gateway interface with OTP verification.
* 📊 **Analytics & Reporting:** Live order status tracking and downloadable revenue reports.
