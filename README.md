## 📌 Overview
The **East West University Cafeteria Management System** is a full-stack web application designed to streamline campus cafeteria operations. It automates order processing, simplifies dynamic menu management, and provides real-time financial tracking and analytics for both administrators and students.

---

## 🛠️ Tech Stack & Architecture

- **Frontend:** HTML5, CSS3, Tailwind CSS, JavaScript (Custom Responsive UI & Glassmorphism Design)
- **Backend:** PHP (Role-Based Authentication, Order Processing & Business Logic)
- **Database:** MySQL (Optimized Relational Schema & Queries)
- **Security:** CSRF Protection, Dynamic Session CAPTCHA Verification, Input Sanitization

---

## ✨ Key Features

- 🔐 **Multi-Role Authentication:** Role-based access control for Students, Faculty, Staff, and Administrators.
- 🍕 **Interactive Digital Menu:** Real-time food browsing categorized with live availability badges and standard pricing.
- 🛒 **Dynamic Cart & Direct Checkout:** One-click item addition with real-time order calculation.
- 💳 **Payment Gateway Integration:** Integrated bKash / Digital Online Payment workflows with automated receipt generation.
- 📊 **Admin Analytics & Reporting:** Comprehensive dashboards for revenue tracking, daily order statistics, and downloadable financial reports.
- 👨‍🍳 **Live Order Queue:** Real-time order status tracking (`Pending`, `Preparing`, `Completed`) for cafeteria staff.
